Commercial Solutions for Classified: Mobile Access, Accredited

Emerging Tech developed a detailed CSfC Mobile Access Capability Package for Langley Air Force Base, from concept of operations through registration and approval.

Client

Langley Air Force Base

Develop a detailed Commercial Solutions for a Classified (CSfC) Mobile Access Capability Package (MA CP) and related documentation to enable Langley’s mission to support and perform relevant experiments needed to meet warfighter requirements related to warfighting software applications.

Key accomplishments

What the Work Delivered

  • Accurate and detailed solution architecture with NIAP/CSfC compliant infrastructure products.
  • Validated CSfC solution with detailed testing evidence and trackable POA&Ms for necessary remediations.
  • CSfC solution registration and approval.
Services provided

How We Delivered It

CONOPS Review

Review and provide inputs to the Langley’s concept of operation (CONOPs).

Architecture Review

Review and provide input to Langley’s solution architecture.

Registration

Register CSfC solution with CSfC PMO and serve as facilitator throughout project duration.

Site Assessment

Conduct site assessment and outline strategy for onsite security assessment.

Stakeholder Coordination

Facilitate security meeting with external stakeholders, document meeting minutes, collaborate with project manager ensuring all activities are tracked and are completed.

Vendor Support

Support vendors with CSfC expertise during implementation and integration of the solution.

Test Planning

Develop security test plans and individual security test cases for IV&V.

IV&V

Perform independent verification and validation (IV&V) of implemented solution and identify deviations.

Capability Package

Develop detailed MA CP, Key Management (KM), Continuous Monitoring (CONMON) matrixes.

Accreditation

Assist ISSM with completing and receiving RMF and CDS accreditation.

Submission

Submit complete CSfC package to CSfC PMO for approval.

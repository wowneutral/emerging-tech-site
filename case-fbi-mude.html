HOME / CASE STUDIES / FBI MUDE

Mobile Unclassified Device Ecosystem — 30,000 devices, 56 field offices.

End-to-end engineering, solution architecture, and cybersecurity support for the FBI’s unclassified mobile program across MDM, MAM, MAS, IdAM, and MCM.

Client

Federal Bureau of Investigation

Following the FBI’s increase in scope of the unclassified mobile program deployment to include Mobile Device Management (MDM), Mobile Application Management (MAM), Mobile Application Store (MAS), mobile Identify and Access Management (IdAM), Mobile Content Management (MCM) and continuous monitoring of all FBI issued mobile devices, Emerging Tech was requested to provide end-to-end engineering, solution architect, and cybersecurity support.

Key accomplishments

What the work delivered.

  • Developed, implemented, and updated over 2000 pages of artifacts to integrate each MDM, MAM, MAS, & MCM solution.
  • Created and implemented device management and the lifecycle strategy for over 30,000 devices located across 56 individual field offices.
  • Scanned, analyzed, and generated security reports for over 500+ mobile applications.
Services provided

How we delivered it.

Analysis of alternatives

Developed multiple Analysis of Alternatives (AoA) plans to compare various mobile implementation strategies for the next generation of mobile devices and security operation solutions.

Lifecycle artifacts

Developed the mobile device inventory, provisioning procedures, device configuration guides, Incident Response Plan (IRP), data security strategy, deprovisioning steps, and many other artifacts to support end-to-end mobile management.

Training

Trained other engineers, security professionals, and Tier II - Tier IV personnel in project management.

Carrier strategy

Designed the security strategy for implementing the multiple mobile network operations (MNOs) across the FBI enterprise to include Verizon, AT&T, and T-Mobile to provide the best cellular coverage across the United States and OCONUS locations.

Policy compliance

Established in compliance with U.S. President’s directives and FBI policies, mobile security content.

Analytics

Developed strategies to capture analytics across devices to enhance service operations and deploy capabilities to end users while maintaining customer experience.

App vetting

Leveraged NIST’s Mobile Application Vetting procedures to develop and implement static code analysis, manual testing, and compliance testing for all of FBI’s mobile applications prior to deployment ensuring sensitive data is protected at all times.
